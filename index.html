Proyecto de una Plataforma Virtual

Acerca de la materia

Bienvenido a Proyecto de una Plataforma Virtual, una materia de carácter práctico-teórico orientada al diseño, planificación y desarrollo de plataformas de software. A lo largo del cuatrimestre integrarás conocimientos de ingeniería de software, gestión de proyectos y desarrollo de sistemas para construir una solución tecnológica completa y funcional.

El enfoque combina fundamentos sólidos de ingeniería con metodologías ágiles del entorno profesional actual. Trabajarás con herramientas de la industria real: control de versiones con Git y GitHub, gestión de tareas, documentación técnica, diseño de arquitectura y desarrollo iterativo.

Al finalizar el cuatrimestre, el alumno será capaz de analizar, planificar y ejecutar un proyecto de software desde su concepción hasta una versión funcional, aplicando buenas prácticas como el uso de ramas (branching), commits descriptivos, revisión de código y pruebas básicas.

Temas principales

Gestión ágil de proyectos Arquitectura de software Diseño de base de datos Documentación técnica Pruebas de software Trabajo colaborativo

Criterios de Evaluación

Parcial 1 y Parcial 2
Criterio Ponderado Aspectos a calificar
Tareas 25% Entrega de actividades en tiempo y forma a través de Classroom y GitHub. No se aceptarán entregas extemporáneas. Incluye actividades realizadas en clase y tareas para casa. Posterior a cada entrega, el alumno deberá explicar su trabajo y responder preguntas relacionadas.
Nota: Se revisarán los logs de Git para validar la hora exacta de la entrega.
Participación 25% Se asignará el puntaje total al alumno (o alumnos) con mayor número de participaciones; el resto recibirá un porcentaje proporcional a su participación. Generalmente consisten en actividades que incluyen programar y que se realizan durante la clase.
Asistencia 5% Asistencia puntual a la sesión. El pase de lista se realiza a las 7:10 AM. Quienes lleguen entre las 7:11 AM y 7:15 AM serán considerados con retardo. Después de las 7:15 AM se contabilizará como falta y no se permitirá el acceso al aula.
Uso de uniforme 5% Asistir a clase con el uniforme institucional completo y en buen estado. El incumplimiento de esta norma implicará la pérdida de este porcentaje.
Examen 40% Evaluación mixta. Incluye teoría, pero aproximadamente el 70% del valor es práctico, por lo que es indispensable demostrar dominio técnico sobre los temas vistos.
